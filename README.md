# PaytmX (Expo React Native)

A sleek, professional mobile financial app design inspired by Paytm. Built with Expo, React Native Paper (Material Design 3), and Expo Router. Includes Home, Payments & Wallet, AI Chatbot Support, Expense Manager, Services, and Profile/Settings screens.

## Run

- Install dependencies: `npm install`
- Start development server (web): `npm run web`
- Or start for native: `npm start`

## Tech
- Expo SDK 51
- React Native Paper (MD3)
- Expo Router tabs
- i18n (English/Hindi)
- Neumorphic touches via elevation/shadow

## Notes
This is a UX prototype with placeholder data. Integrations like UPI, QR scanning, voice input, and ticketing are stubbed for demo.
